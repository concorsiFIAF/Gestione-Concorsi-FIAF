# Gestione-Concorsi-FIAF
Programma per Windows per la gestione dei concorsi fotografici FIAF. Raccoglie in un unico archivio le tue fotografie e la loro partecipazione ai concorsi dei circuiti FIAF

## Versione di prova
La versione gratuita permette di inserire al massimo **10 record**.
Per usarlo senza limiti è necessario acquistare una licenza.

## Download
Scarica l'ultima versione dalla sezione **Releases** (a destra).

## Installazione
Avviando il programma, Windows potrebbe mostrare l'avviso
"Windows ha protetto il PC": clicca "Ulteriori informazioni" → "Esegui comunque".
